# 学习咩 · 保姆级本地运行指南

这份指南帮助你从当前仓库启动 H5 或微信小程序，再按需要启用账号和知识库。项目是前后端分离的：后端监听 8000 端口，H5 预览监听 10086 端口，两个服务需要分别运行。

以下以 Windows PowerShell 为例，从 `AI-Learn` 根目录开始。其他系统使用对应的虚拟环境 Python 路径；不要直接照搬参考项目的自动建库或 `frontend/dist` 导入方式。

## 一、准备环境和配置

先确认 Python、Node.js 和 npm 能运行。MySQL 与微信工具按你准备体验的功能安装，不需要一次配置全部外部服务。

| 环境 | 用途 | 检查方式 |
| --- | --- | --- |
| Python 3.11 | 后端及锁定依赖 | `python --version` |
| Node.js / npm | 前端；本机验证环境为 Node.js 24.19.0、npm 11.17.0 | `node --version`、`npm.cmd --version` |
| MySQL 8 | 登录、云端记录、知识库 | 确认自己的数据库服务可连接 |
| 微信开发者工具 | 小程序模拟器；H5 可先跳过 | 打开工具并导入项目 |

### 哪些密钥需要配置？

密钥都写入 `backend/.env`，不放在前端或文档里。是否配置某项决定对应能力能否使用，缺少密钥不影响健康检查。

| 配置 | 什么时候需要 |
| --- | --- |
| ✅ `DEEPSEEK_API_KEY` | 真实出题、资料判断与报告 |
| ✅ `TAVILY_API_KEY` | 普通主题与公开网页获取；不配时可使用充分正文，不会自动改用模型知识 |
| 🔧 MySQL 与 `JWT_SECRET` | 登录、云端题库和知识库 |
| 🔧 `DASHSCOPE_API_KEY`、`DASHSCOPE_BASE_URL` | 文档向量化；Key 和地址须属于同一地域与业务空间 |
| 🔧 `WECHAT_APP_ID`、`WECHAT_APP_SECRET` | 真实微信登录；本地游客或测试账号体验可先跳过 |

本仓没有 AI 生图或 COS 功能，不需要配置这些服务。`.env.example` 只提供字段与默认值，不包含可用凭据。

## 二、启动后端

创建虚拟环境、安装锁定依赖，并在首次运行时复制配置。已有 `.env` 时保留，避免覆盖之前填写的内容。

```powershell
cd backend
if (-not (Test-Path .venv/Scripts/python.exe)) { python -m venv .venv }
./.venv/Scripts/python.exe -m pip install -r requirements.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

编辑 `.env`，填写上表中需要的配置，然后在同一终端启动服务：

```powershell
./.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 [健康检查](http://127.0.0.1:8000/api/v1/health)，应看到 `code=0`、`data.status="ok"`；[接口文档](http://127.0.0.1:8000/docs) 可查看各接口。修改后端配置后重启，按 `Ctrl+C` 可停止服务。

## 三、启动 H5 或微信小程序

新开一个终端，进入前端并安装锁文件中的依赖。前端只需要后端地址，默认是本机 8000 端口；修改 `.env` 后需要重新编译。

```powershell
cd frontend
npm.cmd ci
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
npm.cmd run dev:h5
```

打开 [H5 预览](http://127.0.0.1:10086)。普通首页可使用游客模式，暂时不配置 MySQL。

### 微信开发者工具

需要看小程序时，在 `frontend/` 执行下列命令并保持终端运行。用微信工具导入 **frontend 目录**，它读取 `project.config.json`，自动找到 `dist/weapp`。

```powershell
npm.cmd run dev:weapp
```

本地游客模拟器保留 `touristappid`。在工具的“详情 → 本地设置”中启用“不校验合法域名”，使本地 HTTP 请求可达；这个选项只用于开发。若本机工具的普通打开入口拒绝游客 AppID，可使用此前验证过的官方 CLI 入口：

```powershell
# 在 frontend/ 执行；安装位置不同则替换 CLI 路径
& 'D:/微信web开发者工具/cli.bat' auto --project (Get-Location).Path --auto-port 9420 --lang zh
```

使用 `auto` 前，在微信工具“设置 → 安全设置”开启服务端口。正式微信登录需让前端 AppID 与后端 `WECHAT_APP_ID` 一致；真机不能访问电脑的 `127.0.0.1`，需要手机可达的后端地址，正式环境还需 HTTPS 和合法域名。

## 四、启用账号与云端保存

本仓 API 启动不会自动建库建表。请先通过自己的 MySQL 管理工具创建应用数据库与专用账号，建议使用 `utf8mb4`，再填写后端配置。

| 字段 | 填什么 |
| --- | --- |
| `MYSQL_HOST`、`MYSQL_PORT` | 数据库地址与端口，默认本机 3306 |
| `MYSQL_USER`、`MYSQL_PASSWORD` | 应用数据库专用账号和密码 |
| `MYSQL_DATABASE` | 已创建的应用数据库名 |
| `JWT_SECRET` | 私有随机签名密钥；不要使用示例短字符串 |

可在本机执行 `./.venv/Scripts/python.exe -c "import secrets; print(secrets.token_urlsafe(48))"` 生成签名密钥，将输出保存在自己的 `.env`，不要贴到对话或仓库。随后从 `backend/` 运行：

```powershell
./.venv/Scripts/python.exe -m scripts.init_db
```

初始化程序按 SQL 创建五张业务表，并升级旧题库的来源、生成方式和索引，重复执行不会清空数据。账号需要目标数据库的建表、读写与 ALTER 权限；不要只执行单个 SQL 文件来代替完整升级。

### H5 本机测试账号

H5 没有正式网页登录入口。本机体验时，在后端 `.env` 设置 `APP_ENV=development`、`DEV_LOGIN_ENABLED=true`；前端设置 `TARO_APP_DEV_LOGIN=true`，API 地址使用 `http://127.0.0.1:8000` 或 `http://localhost:8000`。

重启后端并重新编译前端，在“我的”中选择明确标记的测试账号 A/B。账号题库与最终报告存入 MySQL，未完成进度仍在本机；游客记录不会自动归入账号。正式环境保持开发登录关闭。

## 五、启用私有知识库

知识库需要上一步的账号与数据库，还需百炼向量化配置。填写后端 `DASHSCOPE_API_KEY` 与控制台提供的 `DASHSCOPE_BASE_URL`，默认 `text-embedding-v4`、1024 维；地址必须与 Key 的地域和业务空间匹配，随后重启后端。

从“我的 → 我的知识库”上传 PDF、DOCX、MD 或 TXT，每人最多 10 篇、每篇 10MB。文本使用 UTF-8，PDF 要有可复制文字且无需密码。等待状态变为“已就绪”，再输入具体学习主题开始五题练习。

`backend/data/chroma` 保存向量和片段，`backend/data/uploads` 是临时上传目录，均不提交 Git。只启动一个 API worker；备份时停止业务写入，同时备份 MySQL 与 Chroma。更换向量模型、维度或地域后，旧文档需要删除重传。

## 六、照着验收

先完成一条成功路径，再检查降级和恢复。真实出题会调用你配置的服务；仅检查代码时请使用[维护指南](项目维护指南.md)中的自动化测试。

| 步骤 | 你要做什么 | 应该看到什么 |
| --- | --- | --- |
| 1 | 打开健康检查和 H5 首页 | 健康状态为 ok，首页可操作 |
| 2 | 输入“Python 列表与元组的区别”，开始生成 | 显示生成状态，资料充分时进入五题；如需领域选择，选择后继续 |
| 3 | 提交一题，退出，再从题库继续 | 可见答案与讲解；回来后保留已答进度 |
| 4 | 完成五题并回看报告 | 正确率和 XP 与实际答题一致，每答对一题 10 XP；回看可展开来源 |
| 5 | 登录本机测试账号，完成一轮，再重新打开报告 | 同账号可读云端报告；重复打开不重复增加 XP |
| 6 | 上传有内容的 TXT，等就绪后按主题出题 | 能看到处理状态、生成方式和实际引用；模型兜底时有未核实提示 |
| 7 | 切换账号 B，查看题库与知识库 | 不出现账号 A 的私有数据 |

未配置密钥时，健康检查仍可用，对应功能应给配置提示。普通出题资料不足应保留输入；文档删除后已有报告仍可读。真实微信登录和真机体验需要另行验证。

## 七、常见问题

出错时先确认失败发生在哪一层，避免同时改很多配置。反馈时给出上表步骤号、预期结果、实际结果及脱敏报错，不发送密钥。

| 问题 | 检查方式 |
| --- | --- |
| PowerShell 不允许运行 npm.ps1 | 使用本文的 `npm.cmd` 命令 |
| 生成提示缺少配置 | 检查后端 `.env`，确认从 backend 启动并已重启 |
| 没有 Tavily Key 却无法主题出题 | 本仓普通出题不自动改用模型知识；配置检索或粘贴充分正文 |
| 数据库保存失败 | 确认服务可连、账号权限和数据库名正确，并执行完整初始化命令 |
| 知识库无法上传或处理失败 | 检查登录、百炼地址地域、文件格式、大小与处理失败提示 |
| H5 请求失败 | 后端是否运行；前端 API 地址和后端 CORS 是否匹配 |
| 微信请求被拦截 | 本地开发关闭域名校验；真机使用可访问的地址；正式环境配置合法域名 |
| 8000 或 10086 已占用 | 停止对应旧服务后再启动，不同时运行样品和真实后端 |
| 网页被判为非公开地址 | 保留私网保护；可换公开链接、稍后重试或粘贴正文，勿为通过而关闭校验 |

接口细节见[后端说明](../backend/README.md)，微信构建检查见[前端说明](../frontend/README.md)。
