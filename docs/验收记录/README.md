下表概括开发阶段取得的结果，不把某次模型输出或模拟器测试当作长期保证。正式环境仍需按实际域名、AppID、数据库和持久化目录重新验收。

| 模块 | 已记录结果 | 验证边界 |
| --- | --- | --- |
| AI 出题 | 主题、正文、公开 URL、领域确认、逐题依据与来源保存；历史真实 API 联调通过 | 自动化使用替代响应；历史真实调用是抽样，不能保证每次出题质量 |
| 用户系统 | 账号隔离、云端题库、重复报告不重复结算、H5 与微信模拟器恢复 | 主要使用本机开发身份；真实微信凭据与真机仍待验证 |
| 私有知识库 | 文件处理、文档检索、联网补充、明确提示的模型兜底和云端恢复 | 自动化、历史云端联调及模拟器分别验证；生产持久化需单独核对 |

## 三、原始资料与复验

维护者本机可在 `.local/acceptance/` 找到三份详细验收 Markdown，以及 `qa/`、`knowledge/` 和额外 `verification/` 附件。新克隆仓库不包含这些资料，公开文档不要求它们存在；需要复验时按测试和操作说明重新取得证据。
