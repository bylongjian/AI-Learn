## 三、文档与规范怎么配合

`docs/` 解释项目为什么这样做、怎样运行和维护；`openspec/specs/` 保存已同步的行为规范，`openspec/changes/` 保存进行中的变更。两者应互相引用，避免复制整段规格。

知识库变更 [add-private-knowledge-base-rag](../openspec/changes/archive/2026-10-30-add-private-knowledge-base-rag) 已完成主规范同步并于 2026-10-30 归档。排查当前行为先读 `openspec/specs/`，需要实施背景再读归档；两份复制自参考项目的旧资料已移出正式历史，详见 [OpenSpec 导航](../openspec/README.md)。
