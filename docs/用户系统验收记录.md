## 本机启动与配置

本机已复用现有 MySQL 服务，建立应用库 `ai_learn`、测试库 `ai_learn_test` 与各自独立账号，完成建表及统计索引初始化。应用和测试凭据分别位于被 Git 忽略的 `backend/.env`、`backend/.env.test`，前端本地配置位于 `frontend/.env`。原有 AI 配置保留。不要将这些文件上传或提交。

在两个 PowerShell 终端中分别执行：

```powershell
cd backend
./.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

```powershell
cd frontend
npm.cmd run dev:h5
```

启动后可打开 [个人中心](http://127.0.0.1:10086/#/pages/profile/index)。若端口被其他预览服务占用，先停止对应服务再启动。完整首次安装、数据库建表和字段说明见 [后端运行指南](../backend/README.md) 与 [前端运行指南](../frontend/README.md)。

微信模拟器使用 `npm.cmd run build:weapp` 构建后导入 `frontend`。本机游客 AppID 的官方启动方式为：

```powershell
& 'D:/微信web开发者工具/cli.bat' auto --project (Resolve-Path frontend).Path --auto-port 9420 --lang zh
```

该命令从项目根目录运行，CLI 路径按安装位置调整。用户已手动开启工具服务端口。

## 用户验收步骤

当前测试账号 B 已有本轮真实生成的“Python 函数默认参数与列表基础”示例报告，A 为独立账号。实际数量会随之后的体验增加。

| 步骤 | 你要做什么 | 应该看到什么 |
| --- | --- | --- |
| 1 | 打开个人中心，向下滚动选择“测试账号 B” | 明确标注本地测试账号；初始示例为 40 XP、1 完成关卡、80% 正确率 |
| 2 | 点击“修改昵称”，修改并保存，然后刷新页面 | 新昵称仍在；统计和报告不变；空昵称有校验提示 |
| 3 | 进入“闯关” | 首页显示当前昵称、XP 和最近报告，主题输入功能保持可用 |
| 4 | 点击最近报告，展开“回看本轮题目”，再返回 | 读回完整云端报告、原题与作答；不重新结算经验；返回原入口 |
| 5 | 进入“题库”，搜索 Python，切换“已完成”“未完成” | 搜索与云端状态数量对应；示例位于已完成，未完成为空；清空筛选恢复列表 |
| 6 | 回到“我的”切换测试账号 A | 显示 A 自己的昵称与记录；不出现 B 的报告或 XP |
| 7 | 选择“使用游客模式” | 显示该设备原有游客记录，账号报告不混入游客；可按原流程学习 |
| 8 | 登录 B，输入新主题，按原方式完成五题并查看报告 | 新题库与最终报告写入账号；答对每题 +10 XP，个人统计在保存后更新 |
| 9 | 用另一浏览器访问本机预览并登录同一测试账号 B | 可搜索和打开第 8 步的云端报告；中途逐题进度不会跨设备同步 |

若结果不同，请反馈步骤编号、预期与实际结果、页面报错或截图。样品的布局与昵称操作已获确认，其余页面的使用体验请按以上步骤继续验收。

## 真实微信登录的剩余准备

1. 申请小程序 AppID，将 AppID 写入前端 `project.config.json`；将对应 AppID/Secret 仅写入后端环境文件。
2. 配置手机可访问的后端；正式环境使用 HTTPS 和微信合法请求域名。关闭前后端开发登录开关并重启、重新构建。
3. 在微信开发者工具及真机验证首次登录、重新进入、凭据过期续登、登录失败后游客学习和同一微信账号的云端回看。

当前本机测试登录不能代替真实微信身份验收。本轮未包含生产部署、中途进度跨端同步、游客数据自动迁移和头像上传。
