## 交付内容

正式工程位于主目录 `frontend/`、`backend/`。前端为官方 Taro4.3.1 / React18 / TypeScript / Webpack5；后端为 Python3.11 / FastAPI / LangChain / ChatDeepSeek。五页包括输入、答题、报告、题库和“我的”，本机保存题库、作答和报告。

输入主题或文本后，真实 AI 返回默认5题，含单选、多选和判断；选择后提交、立即讲解，答对+10XP。支持退出续答、报告失败重试、题目回看、题库搜索筛选与个人统计。页面以 prototype 为精确依据，首个样品已由用户确认。

## 真实 AI 验收

连续10组不同主题、3—5题和四种难度配置，逐组生成匹配报告，合计10份题库及10份报告全部通过，无失败事件。出题耗时2.687—4.859秒，报告2.016—2.828秒，均在50秒验收界限内。

验收检查完整JSON、schema、题量/题型比例、非mixed逐题难度、报告与服务端重算统计一致。安全摘要保存在 [live-ai-summary.json](verification/live-ai-summary.json)；逐组进度保留在隔离后端 `.qa/live-verified-progress.jsonl`。不把结构校验等同于所有知识领域的事实准确率评估。

真实联调发现过medium请求返回混合难度，已通过RED回归明确逐题提示，严格业务校验保持不变。原始JSON必须完整，不接受自动补括号、Markdown围栏、尾随内容或非有限数字。异常有界重试，无固定题目生产回退。schema错误日志仅保留白名单错误类型，不记录未知字段名、消息、输入或上下文。

另外，在主目录真实HTTP后端上执行浏览器完整闭环：输入“Python functions and parameters”→真实五题→逐题提交→真实报告；所有题均选A，实际0/5、0%、0XP，页面统计相符，浏览器错误列表为空。截图：[真实AI报告](verification/live-report.png)。这轮调用与固定内容UI回归分开记录。

## 用户复验步骤

启动命令见 [主README](../README.md)。本次预览为 http://127.0.0.1:10086，真实后端为 http://127.0.0.1:8000，接口文档为后端 `/docs`。已停止固定内容QA服务。

| 操作 | 预期 |
| --- | --- |
| 输入空白、超过2000字或正常主题 | 无效输入就地提示且保留；有效主题生成真实题目 |
| 选择答案并提交 | 立即出现正确答案、完整讲解与对应XP |
| 答一半退出，从题库继续 | 当前题、已提交答案与XP恢复 |
| 完成一轮，回看报告 | 正确率与答对数量一致，三句总结、待巩固与建议可读 |
| 题库搜索、筛选，再打开报告 | 结果正确、无结果可清除条件、返回来源正确 |
| 到“我的”并关闭重开 | 本机学习记录与统计恢复 |

本次后台预览提供已构建H5；改源码后需重新构建或改用dev:h5。切换服务前先核对端口和进程命令行；PID会变化，不直接复用旧断点记录中的PID，不结束无关Python进程。
