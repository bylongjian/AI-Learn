# Proposal

## Why

当前 AI 出题只依赖模型训练数据，遇到新知识或同名概念（如 Harness Engineering）时，可能生成其他领域的题目和错误讲解。需求文档要求“AI 自动从全网或者特定的信息源获取知识”，本次补齐出题前的知识获取，并避免资料不足时继续猜测。

## What Changes

- 新增 **知识获取 Agent**：根据主题搜索最新资料，或读取用户提供的公开网页，再将有来源的参考资料交给出题链路。
- 接入 `TavilySearch` 和 `TavilyExtract`，优先采用官方文档、原始文章等直接来源，保留网页地址、可获得的发布日期和检索时间。
- 新增 **领域确认**：检索后仍存在多个合理含义时，展示简短选项；用户选择后重新检索该领域，再生成题目。
- 新增 **资料充分性与题目依据检查**：题干中的事实、正确答案和讲解需要有参考资料支持，不能只检查 JSON 格式。
- **BREAKING**：资料不足、检索失败或搜索服务未配置时暂停出题，提示重试、补充文本或提供参考链接，不再静默使用模型知识出题。
- 为题库附带参考来源与逐题关联，答题讲解中可查看来源；兼容没有来源信息的历史题库。
- **BREAKING**：生成接口增加“待确认领域”业务响应，前端需要识别并展示选项；成功响应保留原题库字段，新增可选参考资料字段。
- 根据审查与用户测试，补齐报告回看来源，修复检索边界和微信主页面重复重建；增加左右整页切换动画，保持出题、计分、登录与保存逻辑独立于动画。

## Capabilities

### New Capabilities

- `web-search-context`: 出题前获取网络或用户提供的资料，检查来源、时效性与内容充分性，约束 Agent 调用，并在依据不足时停止生成。
- `quiz-topic-clarification`: 检索后识别主题歧义，展示领域选项，接收用户选择并重新获取对应资料。
- `learning-page-navigation`: 微信主页面复用、左右切换动效及跳转失败提示，保留学习状态和账号隔离。

### Modified Capabilities

- `knowledge-base-quiz-generation`: 更新“不传 doc_id 时沿用旧出题行为”的要求，使其指向本次有资料依据的出题流程；保留文档检索的其他要求，不在本次实现私有知识库。

## Impact

- **后端**：新增知识获取、资料模型、依据检查与 Prompt；修改实际存在的 `app/services/quiz.py`、`app/models/quiz.py`、`app/routes/api.py`、`app/main.py` 和配置、错误响应。
- **前端**：首页增加领域确认和资料不足反馈；扩展接口类型、题库校验及答题讲解的来源展示。
- **存储**：题库增加可空的参考资料 JSON 字段，云端和本机记录均能保留来源；历史记录继续可读。
- **依赖与配置**：新增 `langchain`、`langchain-tavily`，更新锁定依赖；新增 Tavily 密钥及检索、调用次数、上下文大小配置。沿用当前 `langchain-deepseek` 接入，不迁回归档中的旧适配方式。
- **范围**：以当前代码为基线。本次不恢复归档中的知识库、异步出题任务、文件上传或视频解析；报告接口和计分规则保持现状。
