## 2. 让四类文件能提取成可检索片段

解析只负责文字与来源位置，原文件在解析结束后删除。处理截止时间要能终止解析进程，不能只让前端停止等待。

- [x] 2.1 新增轻量解析模块，按 PDF/DOCX/MD/TXT 提取文字，保留 PDF 页码、统一分块和片段标识；以可终止的独立解析进程运行，检查中文 TXT 和带文字 PDF 的实际片段可读且无虚构页码。
- [x] 2.2 为解析模块补 2～3 个测试：四种格式主流程参数化、无文字层/损坏文件的明确失败、超时终止和临时文件清理；验证失败不会交付“就绪”文档，不测试解析器内部私有函数。
- [x] 2.3 在后端指南补充支持格式、UTF-8、扫描件/密码文件限制和原文件保留方式；按说明制作可复用的小样本，确认文本提取结果与文件内容一致。

- [x] 3.1 实现百炼 HTTP 向量化和原生 Chroma 存取，显式传向量、固定模型配置标识、限制批量及时间；使用确定性测试向量验证写入后重新创建客户端仍能检索。
- [x] 3.2 为向量服务补 2～3 个测试，覆盖真实本地持久化/删除、用户与指定文档双重隔离、Embedding 失败或维度不符时不接受就绪结果；确认 Agent 无法通过参数扩大检索范围。
- [x] 3.3 在后端指南补充模型/维度变化需重传、原生组件安装限制及 MySQL 与 Chroma 的配套备份方式；核对说明与实际目录和 collection 配置一致。

文档分支接入当前同步出题流程，保持现有普通出题要求。只有资料准备失败或不足进入模型兜底，其余业务错误要如实返回。

- [x] 5.1 新增 `services/rag.py` 和对应 Prompt，明确首个文档工具调用、充分性判断、联网工具及参数边界；实现共享 25 秒预算、文档阶段 8 秒、总计最多 4 次工具调用，验证文档足够时不联网，不足时才补充。
- [x] 5.2 扩展 `QuizRequest`、`QuizService` 与 `routes/api.py`：接收已授权文档、有依据时继续逐题核验、无充分依据时按独立 Prompt 生成模型题；保存前事务确认文档仍就绪，并持久化生成方式及原因，验证四种方式均与实际采用来源相符。
- [x] 5.3 为 RAG 准备补 3 个业务测试：文档足够、文档失败后联网补充、两者失败/超时后转模型；工具调用日志同时验证顺序、预算和不外发私有摘录，使用缩短的测试期限，不实际等待 180 秒。
- [x] 5.4 为出题接入补 3 个测试：文档依据题库成功且原流程回归、模型兜底结构和保存信息、非资料错误不降级；最后一项参数化覆盖未登录/他人文档/未就绪、依据审核失败、生成时删除与保存失败。
- [x] 5.5 更新后端生成和来源说明，明确资料准备失败可降级、题目依据审核失败不靠兜底绕过、完整请求仍有 55 秒期限；核对示例中模型兜底的 `reference=null` 且 `generation` 明确可见。
