# 学习咩 HTML 交互原型

这里保留早期页面布局和交互参考，使用固定的模拟题库，不连接后端、数据库或真实 AI。正式小程序与 H5 在 `frontend/`；当前功能请看[项目首页](../README.md)。

## 一、打开体验

直接用浏览器打开 [index.html](index.html) 查看画板，打开 [demo.html](demo.html) 体验模拟学习流程。其余编号页面展示输入、答题、报告、异常状态及题库与个人中心。

## 二、修改与验证

修改 `src/` 下的模型、界面和样式后，在本目录重新构建 HTML。原型测试验证模拟学习状态，不替代正式前后端测试，也不证明真实 AI 质量。

```powershell
npm.cmd test
npm.cmd run build
```

生成的 HTML 由 `build.cjs` 内联脚本和样式，可独立打开。原型不覆盖后续新增的账号、联网引用和私有知识库全部行为。
